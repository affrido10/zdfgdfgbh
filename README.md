# PaperScan — Android-приложение для сканирования документов

PaperScan — самостоятельный Android-проект с интерфейсом на русском языке. По назначению похож на приложения-сканеры документов, но не использует название, логотип или закрытый код Adobe Scan.

## Возможности

- Сканирование с камеры через Google ML Kit Document Scanner.
- Импорт обычных снимков из галереи.
- Определение границ листа, выравнивание/обрезка перспективы и обработка изображения предоставляются экраном сканера Google.
- Многостраничный документ (до 50 страниц на один запуск).
- Экспорт скана в PDF.
- Локальный список созданных PDF: открыть, экспортировать в выбранное место, отправить через системное меню или удалить.
- Приложение не запрашивает широкие разрешения на чтение галереи или доступ к камере: процесс сканирования предоставляется Google Play services.

## Сборка APK

1. Установите Android Studio и Android SDK Platform 35; используйте JDK 17.
2. Откройте папку `PaperScan` как проект в Android Studio.
3. Дождитесь синхронизации Gradle. При первом запуске Gradle скачает необходимые зависимости.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK для установки обычно появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

Можно собрать из каталога проекта командой `./gradlew assembleDebug` (Windows: `gradlew.bat assembleDebug`). При первом запуске скрипт скачает Gradle 8.9 с официального сервера. Для загрузки Gradle и библиотек нужен интернет.

## Требования и ограничения

- Минимальная версия Android в проекте — API 21 (Android 5.0).
- Требуется Google Play services с поддержкой Document Scanner API. На первом использовании Google может загружать компоненты сканера; интернет может потребоваться для этой первоначальной загрузки.
- Документы сохраняются в приватном каталоге приложения. Удаление приложения удалит эти локальные копии; экспортируйте нужные PDF в общую папку устройства.
- В этом окружении нет Android SDK/Gradle, поэтому APK здесь не собирался и запуск на физическом устройстве не проверен. Проект подготовлен для сборки в Android Studio.

## Структура

- `app/src/main/java/com/paperscan/app/MainActivity.kt` — интерфейс и логика приложения.
- `app/src/main/AndroidManifest.xml` — конфигурация приложения.
- `app/src/main/res/xml/file_paths.xml` — безопасная выдача URI для просмотра и отправки PDF.
- `app/build.gradle.kts` — Android SDK и зависимости.
